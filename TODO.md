
## Резервный вариант без Apps Script
- [x] Лист `FORONE_Остатки` переведён на формулы Google Таблиц.
- [x] Артикул, название и остаток подтягиваются напрямую из `Октябрь-Ноябрь`.
- [x] Категория и длина рассчитываются формулами.
- [x] Доступный остаток рассчитывается автоматически с учётом резерва.
- [x] Данные пересчитываются самой Google Таблицей без редактора Apps Script и без триггеров.

## Двусторонняя синхронизация (версия 2.0)
- [x] Серверная часть `FORONE_Sync_v2.gs`: `doPost` принимает операции, `doGet` отдаёт `ping` и `stock`.
- [x] Листы `FORONE_Операции` (журнал) и `FORONE_Ошибки` (сбои), колонка «Расхождение» в рабочем листе.
- [x] Идемпотентность по `operationId`, блокировка параллельных записей, лимиты пакета и количества.
- [x] Ключ доступа и список сотрудников через свойства скрипта.
- [x] `FORONE_setup()` создаёт листы и заголовки, `FORONE_selfTest()` проверяет логику без таблицы.
- [x] Клиентская очередь операций с автоматическими повторами и heartbeat.
- [x] Настройки в карточке `ⓘ`: URL, ключ, сотрудник, устройство, три тумблера, сводка.
- [x] Индикаторы: пилюля «N к отправке», баннер в отчётах, статус и причина в строке журнала.
- [x] Действия человека: «Отправить сейчас», «Сверить остатки», «Поставить в очередь»,
      «↻ Повторить», «✕ Отменить», «↻ Отправить снова», «Убрать», «↩ Вернуть товар».
- [x] Очередь и настройки попадают в резервную копию и восстанавливаются из неё.
- [x] Корректная работа при дублях артикула (реальная база: `H234-YP` — и лувер, и панель).
- [x] Офлайн-поведение и слияние остатков покрыты 226 автотестами (`tests/gs-tests.js`,
      `tests/sync-tests.js`) и сквозным прогоном против учебного Web App
      (`tests/mock-webapp.js`).
- [x] Документация: `README.md`, `SYNCHRONIZATION.md`, `CHANGELOG.md`, `TESTING.md`.
